# 环境与依赖说明（七星使者自动抠像标准 V1）

## 路径约定（全部可移植，不写死用户名）
| 用途 | 默认路径 | 可用环境变量覆盖 |
|---|---|---|
| 独立虚拟环境 | `$HOME/venvs/birefnet-matte` | `BIREFNET_VENV` |
| **模型权重目录** | `$HOME/models/birefnet-weights` | **`BIREFNET_WEIGHTS`** |
| uv 可执行文件 | `$HOME/.local/bin/uv` | — |
| uv 下载缓存 | `$HOME/.cache/uv` | — |
| HuggingFace 缓存 | `$HOME/.cache/huggingface` | — |
| ffmpeg | `PATH` 中的 `ffmpeg` | `FFMPEG` |

> **模型权重不入库**（`.gitignore` 已排除 `*.safetensors` 等），新设备需按下节第 4 步单独下载。

## 版本锁定（本机实测）
- Python 3.12.14（由 uv 提供的独立 CPython，**不修改系统 Python**）
- torch 2.14.0 · torchvision 0.29.0 · timm 1.0.29 · transformers 5.17.0 · kornia 0.8.3
- opencv-python-headless 5.0.0 · numpy 2.5.3 · pillow 12.3.0
- ffmpeg 9.0.1（需支持 `prores_ks` 与 `libx264`）

## 硬件前提
- Apple Silicon（本机 Apple M4 / macOS 15.7.3 / 16 GB 统一内存）
- `torch.backends.mps.is_available() == True`
- 单条素材处理峰值临时占用 < 1 GB

## 安装 / 卸载
```zsh
# 安装（uv + venv + 依赖 + 权重）
zsh environment/install_install_uninstall.sh

# 卸载（必须显式 --uninstall，并输入 yes 二次确认；仅删除脚本列出的明确路径）
zsh environment/install_install_uninstall.sh --uninstall
```

## 关键注意事项
1. **必须在普通终端运行**（非受限沙箱），否则 MPS 无法访问 Metal 设备
2. 权重为 **fp16**：输入张量必须匹配 `dtype=torch.float16`，否则报
   `Input type (float) and bias type (c10::Half) should be the same`
3. HuggingFace 官方代码依赖 `kornia`，缺包会报
   `This modeling file requires the following packages that were not found ...: kornia`
4. 模型授权：`ZhengPeng7/BiRefNet` 为 **MIT**，可用于商业项目；权重需自行下载并遵守其许可
