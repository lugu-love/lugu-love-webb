# 风信兔 · 角色动画标准坐标系（RCS v1）

> 目标：任何情绪/使者的动画，进入正式 preview 前先经同一自动标准化，
> 使**文件内部兔子的视觉坐标与尺度**统一；各场景（A路/漂流瓶/地球/成片）用一套全局参数即可，不需要逐情绪调位置。

## 1. 虚拟标准画布（与分辨率无关，输出时按需缩放）
- 方形画布：边长 = 1000（归一化单位）
- 兔子**整段动画 union bbox**（含耳朵/脚/手臂/飘带/快速动作）为“内容盒”

## 2. 统一几何约束（自动完成）
| 项 | 值（相对画布） |
|---|---|
| 内容盒目标高度 | 78%（=780） |
| 内容盒最大宽度 | ≤90%（=900） |
| 底部基线（脚/落地） | y=910（底部安全边 9%） |
| 顶部安全边（耳朵） | 当按高度缩放时 = 13%（130） |
| 水平中心 | 500（左右居中） |
| 左右安全边 | 内容盒宽≤90% 时 ≥5% 每侧 |

- 缩放规则：`scale = min(780/unionH, 900/unionW)`
- 垂直锚定：union 底部对齐基线 y=910
- 所有帧共用同一变换 → 无抖动；动作全程不裁切

## 3. 允许例外
- 极特殊动作（躺倒/大跳跃等）若连 90% 宽度都放不下：仅允许 `stageOverride`，
  作为例外机制，正常 95%+ 情绪应为零人工配置。

## 4. 资产输出
- 标准方形透明帧（本目录 mobile/<E>/sheet-*.webp，RGBA，12帧/表）
- 每帧内部构图均满足上表；`metrics.json` 记录实际边距供校验

## 5. 场景消费
- 场景只持有全局参数：状态1/2/3/4 各一套 (x, y, scale)
- 标准化精灵 + 全局参数 = 任意情绪直接正确
