# 面对面聊天 Life Loop V1

本目录只存放面对面页面的轻量生命循环视频。

## 生成原则

- 480×640
- 24 fps
- H.264 / yuv420p / faststart
- 无音轨
- 黑色背景，页面沿用现有 `mix-blend-mode: screen` 显示
- 2.6–3.2 秒无缝循环
- 仅做极轻呼吸、重心和微小位移，不做情绪剧情

## 本轮来源

除云栖考拉外，六位角色现有素材中没有可直接复用的中性动作视频。现有狐狸祝福视频和兔子情绪库属于明显动作/情绪内容，本轮没有强行使用。

六段 V1 由角色高分辨率 `main.png` 生成：

- 风信兔：呼吸 + 很轻纵向变化
- 光尾狐：呼吸 + 很轻横向/纵向变化
- 星语鹿：呼吸 + 很轻纵向变化，无长尾
- 暖山熊：慢呼吸 + 很轻身体起伏
- 凌遥猴：轻微重心变化，不做搞怪动作
- 玄星猫：呼吸 + 很轻横向/纵向变化

这些是技术底座，不替代未来正式制作的中性呼吸、眨眼、耳朵微动资产。
